::: note

**Centos停更说明：**

CentOS操作系统已全面停止维护（EOL），继续使用会使系统暴露在新的安全漏洞之下，成为攻击目标，并可能违反相关安全合规要求。

阿里云：[Centos 操作系统](https://help.aliyun.com/zh/ecs/user-guide/options-for-dealing-with-centos-linux-end-of-life)

:::

Centos 是 Linux 发行版之一，它是来自于 Red Hat Enterprise Linux 依照开放源代码所编译而成。CentOS 发行版操作系统是目前企业使用最多的系统之一，2016年12月12日，CentOS基于 Red Hat Enterprise Linux 的 CentOS Linux7 (1611) 系统正式对外发布。
